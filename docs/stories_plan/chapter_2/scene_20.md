# Scene 20: 排好的聲明

- **Summary:** 直播結束滿一週的上午，黑瀨來電一條一條交代重新調查的結果；正午，真白一週前排好的五句聲明準時發出，母親也公開了會計師報告的結論頁。

[場景：相馬事務所，直播結束滿一週的上午，細雨漸小。窗外天色從灰轉白，案前的桌面已經收乾淨，筆電開著，牆邊側櫃上那台壞掉的咖啡機貼著「勿按」便條。]

[早坂茜推門進來，傘尖還在滴水。她把手上的紙袋放到桌角。]

**早坂茜**：早。路口那家剛開，我買了飯糰。

**相馬律**：我吃過了。

**早坂茜**：你吃過的是昨天剩的那半片吐司。

[相馬律沒有反駁，伸手把紙袋拉近。]

**相馬律**：……鮭魚的？

**早坂茜**：梅子的。鮭魚我自己要。

[她把外套掛好，目光掃過側櫃。]

**早坂茜**：那張紙，一個禮拜了。

**相馬律**：沒再吐過水。算有用。

**早坂茜**：算。

[早坂茜從公事包側袋摸出一小包薑糖，放在他的紙杯旁邊。]

[相馬律低頭看了一眼那包薑糖，沒有拆，只用指腹把皺掉的角壓平。]

**相馬律**：電話，幾點？

**早坂茜**：他說上午。沒說幾點。

[相馬律的手機在桌面上震動起來。螢幕上是黑瀨徹的名字。他按下擴音。]

**黑瀨徹**：相馬，早坂，都在嗎？

**早坂茜**：在。你說。

**黑瀨徹**：我一條一條講，講完你們再問，我能答的才答。

**相馬律**：好。

**黑瀨徹**：第一條。今天凌晨，警方以涉嫌殺害如月真白，逮捕了蓮見透。

**相馬律**：……他怎麼說？

**黑瀨徹**：到案之後，只說要等律師。沒有自白。

**黑瀨徹**：第二條。警方調了那支登記手機的通訊紀錄。

**黑瀨徹**：SR-2307 的通行碼進了手機之後，沒有轉寄，也沒有撥給任何人。

**黑瀨徹**：所以警方的認定是，這組碼沒有交到別人手上。

**早坂茜**：認定。我記下了。

**黑瀨徹**：第三條。七樓上發生的事，還有他是怎麼做的。

**黑瀨徹**：那是檢方的案子。起訴書裡才會有。

**黑瀨徹**：辯方沒有立場問，我也不會說。

**黑瀨徹**：第四條。三枝悠真。

**黑瀨徹**：檢方不起訴的通知書，今天早上到了。

**早坂茜**：我這邊也收到副本了。他的辯護委任，今天就算結束。

**黑瀨徹**：KAGAMI 那邊，摘要的更正公告也上線了。

**黑瀨徹**：只有一行，放在頁面最底下。

**黑瀨徹**：「高度關聯人物欄位更正：三枝悠真，撤回；蓮見透，列入。」

**黑瀨徹**：轉發數，原本那則摘要是幾十萬。這一行，兩百多。

[相馬律沒有說話，視線落到窗外。雨絲細得幾乎看不見。]

**相馬律**：……知道了。

**黑瀨徹**：最後一條，跟正午那則貼文有關。

**黑瀨徹**：如月真白的母親是法定繼承人。她簽了同意書，請平台照排程發出。

**黑瀨徹**：之前說不發，是還沒人能簽字。現在她簽了。

**黑瀨徹**：原件警方也存好了，發出去，不影響偵辦。

**早坂茜**：她本人，怎麼說？

**黑瀨徹**：她只說了一句。「那是她自己寫的，我沒有資格改。」

**黑瀨徹**：然後她說，要去澆花了。警方這幾天陪她進去。窗台那兩盆，她每天澆。

**早坂茜**：……每天。

**黑瀨徹**：條目就這些。有問題，現在問。

**相馬律**：沒有了。

**早坂茜**：沒有。謝謝你，黑瀨先生。

**黑瀨徹**：十二點，我在局裡看。

[通話結束，擴音器安靜下來。早坂茜把空掉的紙杯捏扁，丟進腳邊的紙簍。]

**早坂茜**：還有三個小時。

[相馬律拆開飯糰的包裝，咬了一口。]

**相馬律**：梅子，很酸。

**早坂茜**：我挑的，我負責。

[場景：同一間事務所，正午前。筆電的螢幕占滿畫面，只剩一片發光的頁面，窗外的雨又細了一些。]

[筆電螢幕右下角的時鐘，跳到 11:58。早坂茜拖了張椅子，坐到相馬律旁邊。]

**早坂茜**：兩分鐘。

**相馬律**：嗯。

**早坂茜**：備用帳號的頁面，我開著了。不重新整理，等它自己出現。

**相馬律**：好。

[相馬律的雙手交握在桌上，指節慢慢扣緊，又鬆開。]

**早坂茜**：你不用盯著手看。

**相馬律**：沒有盯。

[時鐘跳到 12:00。頁面停了一拍，然後最上面多了一則貼文。]

**早坂茜**：發出來了。十二點整。

**早坂茜**：我來念。

**早坂茜**：「我是如月真白。這篇是我自己寫、自己排的。」

**早坂茜**：「玻璃箱企劃結束以後，我會離開現在的事務所。」

**早坂茜**：「過去三年的收益，我已經請外部的會計師核對。」

**早坂茜**：「結果出來，我會自己說明。」

[早坂茜的聲音停在這裡。]

[事務所裡沒有人說話。窗上有一滴雨，慢慢滑到窗框。]

[場景：事務所，午後剛過。細雨還在下，窗外的灰變得很淡，桌上的飯糰包裝紙還沒收。]

[相馬律把視線從螢幕上移開，輕輕吐出一口氣。]

**相馬律**：……五句。

**早坂茜**：五句。

[筆電傳來一聲提示音。早坂茜低頭點開訊息。]

**早坂茜**：黑瀨先生傳來的。母親把會計師報告的結論頁，也公開了。只有結論頁，跟聲明同一天。

**相馬律**：念吧。

**早坂茜**：「過去三年。」

**早坂茜**：「事務所轉給如月真白的金額，比合約規定的分成，少了將近四成。」

**早坂茜**：「三十六個月，沒有一個月例外。」

**早坂茜**：「與如月真白本人手寫的對照表相符。」

**早坂茜**：這是會計師的認定，頁面上就寫了這幾行。

[相馬律點了一下頭，沒有接話。]

[畫面角落的數字開始往上跳，一下，又一下。]

**相馬律**：嗯。

[早坂茜把那包薑糖推到他手邊。相馬律拆開，含了一顆，兩個人一起看著計數往上走。]
