# Scene 4: 隔著玻璃 — 澀谷玻璃箱廣場

- **Summary:** 案發當天中午，相馬與早坂來到玻璃箱廣場核對摘要四點；粉絲戶川堅稱親眼拍到箱內的真白，但站上她的拍攝位置才發現，影片裡最清楚的身影是映在箱子側面玻璃上的直播牆——這只說明她拍到了什麼，摘要仍然站得住。
