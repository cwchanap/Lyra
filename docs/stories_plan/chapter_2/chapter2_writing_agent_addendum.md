## 0. 寫作總目標

第 2 章的成稿要讓玩家得到三種感覺：

1. **我也以為自己看見了。**
   開場時玩家和數萬觀眾一樣，相信玻璃箱是透明的、直播是現場、真白不可能被帶走。
2. **每個人都只看見自己那一小塊。**
   群眾看牆、控制室看合成畫面、保全看綠色狀態、經紀人站在第一回報位置。沒有人全盲，也沒有人全知。
3. **一個靠被觀看維生的人，被「所有人都看見了」這件事吞掉。**
   真白不是線索容器。她累、她想休息、她想替自己說話。

本章方法論升級（相馬自己會在 Beat 8.5 說出口，前面只演不講）：

> 第 1 章問「這筆紀錄到底記了什麼？」
> 第 2 章問「這個人站在哪裡，又透過什麼看見？」

## 2. 不可改動的邊界

### 2.1 不可改案件骨架

- 被害人：如月真白。表面嫌疑人：三枝悠真。真兇：蓮見透（真白經紀人）。
- 動機：蓮見長期侵吞直播收益；真白準備退出公司、把帳目交給外部會計師，並排程不可由蓮見撤回的公開聲明。
- 死因：頸部壓迫窒息，就地兇器為活動方寬版工作證掛繩／束線掛帶。
- 時間鎖、sponsor format、控制室四步誤判：完全照 plan §2.1、§4。

### 2.2 不可提前揭露（全章）

- 不說 A-90、ZERO WITNESS、`ZW_A16.lock` 解碼。
- 不讓雨宮現身；雨宮只在 Beat 7 發「別看牆」。
- 不鑑定藍傘；不證明青葉重演內容為假；不揭露重演依據誰的視角。
- 不把 sponsor mode 的九十秒 Silent Visual Challenge 寫得像 A-90。它只是本章導播格式。
- 不讓蓮見成為鏡原代理人或青葉知情者。

### 2.3 Beats 0～3 的額外封印

Beats 0～3 是玩家「跟著群眾一起看錯」的段落。以下在這四場**一律不得出現**：

- 畫面上**不得**呈現真白離箱、走進服務核心、或與蓮見同行。
- 開播後到贊助段之前，真白**全程不出箱**，沒有例行的出箱休息。休息時段只是箱內靜音（麥克風關、直播不停），工作人員隔著玻璃用對講話筒交談、用艙口旁的小傳遞口遞東西。開播後服務艙口只屬於緊急安全流程。這是本章「她不可能被偷偷移走」錯誤前提的根基，後續 beat 不得改寫。
- 耳麥流程通道的**指示內容不得被玩家聽見**。可以呈現「贊助模式時耳麥會切到流程通道」這條公開規則（safety briefing），不能呈現蓮見在午夜對她說了什麼。
- 不出現十五分鐘通行碼、M-03、服務梯 B 內部、request ID 的具體數字或有效時段。控制室可以說「維修申請是有效的」「狀態還是綠的」，不說誰申請、幾點失效。
- 不描述兇器（掛繩／掛帶）。屍體發現只寫到「頸部有壓迫痕跡」為止。
- 不讓任何角色說出「直播不是現場」「牆不是箱」這類本章答案句。三枝那句難聽真話留到 Beat 6。
- 不出現雨宮訊息、外送員、流出短片、QA 快照。
- 蓮見在這四場是**最冷靜、最有用的大人**。他可以有一處「替真白按停」的控制感（Beat 0 語音備忘），一處「人在背面安全位，我去接」的第一回報（Beat 2）。其餘不加任何可疑描寫：不擦汗、不躲眼神、不看錶、不提前知道屍體位置。

### 4.1 共同設定

- 季節與天氣：雨鐘案結束後的幾週，晚秋。澀谷夜裡細雨時有時無，廣場上滿是傘。玻璃箱設在廣場中央、有頂棚，箱本身不淋雨。
- 玻璃箱：平時真的透明，看得見真白、椅子、桌上的資料座。箱背面有服務艙口與「背面安全位」。廣場正面是巨大直播牆。
- 活動方：控制室設在廣場邊的活動轉播車（OB van）內。導播、助理導播、公關、活動保全在 Beats 0～3 只用職稱稱呼。
- 時間顯示：贊助段內節奏用 `S+00m45s` 這類 offset 只出現在後段證物；Beats 0～3 台詞用真實鐘點（「十二點」「十二點零三分」）。

### 4.2 Beat 0（scene_0）必含

- 00:40：箱背面，真白錄語音備忘。玩家只聽到開頭「做完這次，我想休息一個月……」；蓮見伸手按停：理由溫和（「等等就開播了，留點聲音」之類）。完整備忘留給 Phase C 支線，不在此說完。
- 00:50：safety briefing（活動保全或導播主講，蓮見在旁點頭）。必須公開說明三件規則：
  1. 贊助段的「靜默挑戰」中，主播不對鏡頭說話、不自由互動。
  2. 若贊助段中發生安全異常，主播**不得在直播中臨時說明安全流程**，而是前往玻璃箱背面安全位，由導播／經紀人在前場補場。
  3. 贊助模式時，耳麥會從節目通道切到流程通道。
- 手機放進箱內資料座，整個直播期間留在箱內。
- 01:00 開播：從廣場群眾視角建立「透明、公開、數萬人看著」。
- 可選的人味細節：真白說透明傘像小學生用品（plan §15 允許），但**不得**出現藍色透明傘。

### 4.3 Beat 1（scene_1）必含

- 第 1 章章末，真白的青葉預告在網路留下討論。
- 相馬事務所的日常（雨鐘案收尾文件、壞咖啡機之類的物件記憶），背景播放真白直播：她宣布把「司法科技與青葉都市傳說」排入正式企劃。相馬手停半拍、移開視線，**不閃回、不頭痛、不說青葉**。早坂不對青葉有任何情緒反應（她的私人連結是主線封印）。
- 箱內靜音休息時段（真白不出箱；蓮見在箱外隔著玻璃用對講話筒說話）：蓮見勸她別碰，理由只能是「不賺錢、惹麻煩、贊助商不喜歡」。蓮見語氣溫和、像在替她著想。
- 真白平板上開著兩份青葉資料（一張網路流傳截圖、一份官方資料庫頁面）。她把平板收起來。**不比對、不描述兩者差異、不出現頁腳文字。**
- 早坂與相馬此時與案件無關，不得預知事件。

### 4.4 Beat 2（scene_2）必含

- 23:40：三枝在自己的工作室直播，嘲諷玻璃箱企劃（自然介紹這個新角色；他討厭、投機、蹭流量）。他說他十二點要關台「看她翻車」。這是 KAGAMI 摘要後來抓住的空白時段。
- 00:00：主持人口播與看板引導觀眾「請看主螢幕」；燈光下降、正面投影啟動。
- 00:00:30～00:02:00：靜默挑戰。群眾與粉絲從直播牆看見「真白靜靜坐著」，稱讚她一動不動。只寫他們看見的東西，不寫箱內真相。
- 00:03 起控制室四步誤判，照 plan §4.2：
  1. 導播：判斷為前面板投影掉層／同步異常。
  2. 助理導播：呼叫背面待命；收到蓮見回覆「人在背面安全位，我去接」。
  3. 公關：維修申請有效、贊助設備異常，先準備技術異常公告。
  4. 活動保全：申請狀態仍是綠色、沒收到失聯標記，不封鎖後場通道。
  每一步都要合理，不讓任何人降智。
- 00:15～00:25：升級為「失聯」，第一封鎖時機已錯過。前場開始騷動。
- 約 00:33：蓮見回到前場，冷靜接手對外溝通與找人。可以有一句助理導播「蓮見先生剛剛去哪了？」→「去背面接人，安全位沒人」這類合理回答；**不寫他氣喘、濕透、受傷或神色不對**。

### 4.5 Beat 3（scene_3）必含

- 約 02:30：樓宇保全因服務梯超時停靠、消防門沒回彈，上空置樓層查看，發現真白。寫到「頸部有壓迫痕跡」為止，不描述兇器。
- 早晨：新聞與 KAGAMI 證據摘要。摘要（orchestrator 定版，後續 beat 沿用）列出四點：
  1. 平台影像顯示真白直到約 00:14 仍在箱內。
  2. 23:40 三枝公開嘲諷企劃，雙方有長期對立紀錄。
  3. 三枝工作室與發現屍體的商業大樓在同一街區。
  4. 三枝 00:00 關台後沒有公開動態，無人能證明他的行蹤。
  摘要結論：「高度關聯人物：三枝悠真」。輿論（路人、留言）迅速跟著摘要走。
- 相馬事務所：早坂帶著案子進門。三枝被請到澀谷署說明，他要求律師；法律扶助的值班名單把案子排到早坂。第一輪證據摘要審查會很快就會開（給出明確期限，製造壓力）。
- 澀谷署詢問室：自然介紹三枝與兩人的初次見面。三枝態度難看：嫌麻煩、拿死者開玩笑、只在意頻道，讓玩家更願意相信他有罪。他**不得**說出「直播不是現場」。
- 收尾：相馬與早坂決定先去廣場現場（銜接 Beat 4 Phase A）。

## 5. 角色聲音指南（第 2 章新角色）

相馬律、早坂茜的聲音沿用 `characters.md` §1 與第 1 章 addendum §4。第 2 章時兩人已一起辦完雨鐘案，默契比第 1 章自然：早坂會直接把文件分好堆塞給相馬，相馬會先替她買熱飲。

### 5.1 如月真白

狀態：人氣直播主，二十四、五歲。鏡頭前明亮、熟練；鏡頭外累、乾、說話很省。

台詞特徵：

- 直播中：短句、口頭禪式的親切，熟練地接彈幕。
- 鏡頭外：語氣平，句子更短，偶爾一句乾笑話。
- 她想替自己說話：「這個我自己決定」是她的核心，但她不吼、不哭。

可用語感：

> 「好——今天也在箱子裡，大家都看得到我吧。」
> 「休息的時候，別幫我回訊息。」
> 「這題目我想自己做完。」

避免：

- 變成悲劇預告（「如果我出事……」）。
- 把她寫成調查青葉的偵探或說出青葉資料的意義。
- 讓她直接對蓮見表現恐懼或敵意；她還信任這個工作流程。

### 5.2 蓮見透

狀態：真白經紀人，三十代後半。整齊、冷靜、永遠在「處理」。他的控制不是兇狠，而是替她說話、替她取消、替她解釋。

台詞特徵：

- 溫和、合理、用「我們」說話。
- 常用工作語：「我來處理」「先照流程」「這個我去談」。
- 從不提高音量。

可用語感：

> 「先照流程走，其他的我來。」
> 「這種題目不賺錢，贊助商也不會喜歡。」
> 「人在背面安全位，我去接。」

避免（Beats 0～3）：

- 任何反派式暗示、冷笑、意味深長的停頓。
- 讓他提起掛繩、通行碼、維修申請的細節。
- 讓他對屍體位置、死因表現出不自然的熟悉。

### 5.3 三枝悠真

狀態：競爭直播主，二十代後半。可憎、投機、蹭流量，懂直播圈的骯髒細節。本章是錯誤嫌疑人；後章會回收，不得洗白成可靠盟友。

台詞特徵：

- 嘲諷、口語、帶直播用語。
- 先保護頻道和流量，再保護自己。
- 說話難聽，但偶爾說中一點直播圈的實情（真正那句「直播不是現場」留到 Beat 6）。

可用語感：

> 「二十四小時坐在玻璃箱裡？那叫企劃還是展示櫃？」
> 「我巴不得她翻車。但人死了，我拿什麼蹭？」
> 「律師是吧。先講好，我的頻道不能停。」

避免：

- 讓他在 Beats 0～3 顯得可憐或無辜。
- 讓他提供任何破案資訊。

### 5.4 控制室四人

- **導播**：技術人，先看信號再看人。句子短、術語少：「前面板掉層了」「先別切畫面」。
- **助理導播**：忙、快、靠無線電活著。合理信任經紀人回覆。
- **公關**：先想對外怎麼講。「先發技術異常，別用失蹤兩個字」。
- **活動保全**：照規章。「狀態還是綠的，沒有失聯通報我不能封後場」。

四人都**不是**降智或推卸；每個判斷在當下都說得通。

### 5.5 只出聲、不出臉的角色

`主持人`、`粉絲甲`、`粉絲乙`、`樓宇保全`、`新聞主播` 在 `characters.yaml` 是 `portraitMode: none`。路人仍可用 `路人甲／乙／丙`。

  - 看的是牆：廣場上的觀眾（`sponsor_mode_signboard`）、戶川手機拍到的畫面（卡 `togawa_phone`，來源 `togawa_video_position_check`）。後者只記她的手機拍到了牆在玻璃上的倒影；板的 Prompt 與這一欄的 Description 因此同時涵蓋視線和鏡頭，分欄不決定她用自己的眼睛看見什麼（那是戶川的說法，影片判斷不了）。
  - 看的是別人送出來的畫面：轉播車門邊的監看螢幕（`program_composite_label`）、平台上的觀眾（`platform_archive_rule`）、在家看直播的三枝（`statement:saegusa_watched_until_cut`）。
  - 看的是箱子本身：側巷裡的柚木（`statement:rider_side_view_account`）。
  - 完成後確立事實 `crowd_watched_the_wall`；plan §8.1 的完成結論「群眾沒有集體說謊。他們只是被安排去看同一面牆。」在 Result Dialogue 由相馬說一次。
- **畫面板** `footage_board`（classify，視線板完成後解鎖）：
  - 送出去的那一路是合成的：監看畫面標籤、贊助模式音訊路由、平台保存規則。轉播車這一側只指門邊標示 Program Composite 的監看畫面與保存的 PGM 輸出（`investigation_scene_12` 的 PGM 錄影機）；板的 Prompt 與這一欄的 Description 都照這個範圍寫，不說「整輛轉播車」。
  - 車內的即時預覽（`monitor_wall` 的 C1 與整面小螢幕）看得到，只是不存：它們不是這一欄的卡，也沒有被這兩個事實排除。
  - 整晚都留在箱子裡的東西：箱內手機資料座、投影輪廓板（plan §5：手機位置不能等於本人位置）。
  - 沒經過合成的，只剩碎片：原始信號短時緩存、後台流出短片。
  - 完成後確立事實 `footage_is_not_direct_box_observation`；plan §8.2 的完成結論「影像是真的。但不是那一刻箱內的直接觀測。」在 Result Dialogue 由相馬說一次。

### 14.4 Beat 8.5 封印（沿用 §2.2、§8.3、§11.3、§12.3、§13.3，並追加）

- 兩塊板只分「誰看著什麼」與「紀錄說明哪一層」：不推真白幾點離箱、去了哪裡、怎麼離開，也不說她當時已經不在箱內。
- 柚木那一張卡只記到「不像人在動」：他沒說的，不替他補。
- 三枝那一張卡記的是他自己的說法（「他說他在家…」）：放進「看的是別人送出來的畫面」只分類視線，不洗清他的行蹤。
- 保全室有沒有看節目畫面，目前沒有任何紀錄；Beat 8.5 只說轉播車與平台。保全室的監看要等之後的 beat 有紀錄才可以說。
- 投影輪廓板仍是贊助商正當的投影道具，放在「整晚都留在箱子裡的東西」，不叫「替身」，也沒有人用它假裝她。
- 戶川那一張卡只分類她的手機拍到了什麼：不決定她用自己的眼睛看見什麼。
- 兩個事實對轉播車只涵蓋 Program Composite 監看畫面與保存的 PGM 輸出；車內的即時預覽存在、只是沒有保存，後續 beat 不得拿這兩個事實排除那些預覽。
- 分析場景沒有調查互動點，不計入 §13.6 的互動點比例。
